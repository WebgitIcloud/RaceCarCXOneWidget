Only used when Environment is Custom. For example web-modules-de-uk1.niceincontact.com

The widget can only start once per page, so saving reloads the page. Settings are saved in this browser. You can also pass them in the URL, for example ?brandId=1234&channelId=chat_xxx&env=UK1.

Widget styles (CSS)

This CSS is sent to the widget with cxone('chat', 'setCustomCss', …) when the page loads. Applying changes here updates the open widget straight away, so you can try things before saving.

Target elements with [data-selector="…"] or [class*="Name_Name"]. The hashed part of class names changes between widget releases, so do not use it.
